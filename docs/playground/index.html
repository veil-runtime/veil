Build an interface. See it work.

Real Veil UI 0.4.0. Edit JSON, render it, and interact locally. No Core, model or backend required.

Definition

Live preview

Actions only change local demonstration data. “Approve” grants no permission and executes no external work.

Inspect state, data and validation

Bindings read state or host data. Validation covers visible fields; a validated button blocks dispatch until they pass.

Action and error history
The host authorizes the demo action and owns effects. History is limited to 20 entries.

Use it in your application
npm install @veil-runtime/ui@0.4.0
Copy the definition into definition.json. In your browser bundle:
import { createMountedInterface } from '@veil-runtime/ui/dom';
import definition from './definition.json';
const target = document.getElementById('app');
const ui = createMountedInterface(target, definition, {
  allowedActions: ['demo'],
  onEvent(event) {
    ui.updateData({ ...ui.snapshot().data,
      message: 'Local action received' }, event.revision);
  },
});
// On teardown: ui.dispose();
Provide <div id="app"></div> and bundle with your application's build tool. UI emits events; your host owns policy, data and effects. A host could submit an authorized plan to Core. UI 0.4.0's optional Core peer range is ^0.4.0; Core 0.6.0 compatibility is not yet qualified.


Definitions, not executable code
Supported built-ins: Stack, Row, Heading, Text, Status, Input, Select, Textarea, Button, Table and List. Text, number and checkbox inputs are supported. This playground allows only the local “demo” action, registers no custom components, and caps JSON at 32 KiB. Rejected candidate preparation preserves the last working preview. A renderer exception during commit cannot generally undo already applied DOM changes or external effects.
The AI descriptor example is static; no model is connected. Natural-language AI generation is deferred. A future provider-independent adapter would need a protected server endpoint, rate and byte limits, and validation of returned JSON. These examples are deterministic templates, not AI generation.
