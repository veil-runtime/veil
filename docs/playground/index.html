Developer portal · UI guide

Build an interface. See it work.

Real Veil UI 0.3.0. Edit JSON, render it, and interact locally. No Core, model or backend required.

Definition

Live preview

Actions only change local demonstration data. “Approve” grants no permission and executes no external work.

Use it in your application

npm install @veil-runtime/ui@0.3.0

Copy the definition into definition.json. In your browser bundle:

import { createMountedInterface } from '@veil-runtime/ui/dom';
import definition from './definition.json';
const target = document.getElementById('app');
const ui = createMountedInterface(target, definition, {
  allowedActions: ['demo'],
  onEvent(event) {
    ui.updateData({ ...ui.snapshot().data,
      message: 'Local action received' }, event.revision);
  },
});
// On teardown: ui.dispose();

Provide <div id="app"></div> and bundle with your application's build tool. UI emits events; your host owns policy, data and effects. A host could submit an authorized plan to Core. UI 0.3.0's optional Core peer range is ^0.4.0; Core 0.6.0 compatibility is not yet qualified.

Definitions, not executable code

Supported built-ins: Stack, Row, Heading, Text, Status, Input, Button, Table and List. Text, number and checkbox inputs are supported. This playground allows only the local “demo” action, registers no custom components, and caps JSON at 32 KiB. Invalid updates preserve the last working preview.

Natural-language AI generation is deferred. A future provider-independent adapter would need a protected server endpoint, rate and byte limits, and validation of returned JSON. These examples are deterministic templates, not AI generation.
