Runtime and host
Veil UI validates descriptors, renders built-in components, owns bound field state and emits declared actions. The host selects scenarios, checks actions and phases, controls timers, handles failures and owns all external effects. This page uses no live model or infrastructure service. A production host must authorize effects server-side.
