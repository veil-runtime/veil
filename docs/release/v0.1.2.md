# v0.1.2 Release Work

v0.1.2 publishes the contextual execution authorization and inbound MCP adapter
contracts added after the `v0.1.1` tag. It also contains the public-release
remediations required for the current repository snapshot.

The public root now exports `ExecutionAuthorizer`,
`CapabilityAuthorizationContext`, `CapabilityAuthorizationDecision`, and
`OperatorRuntimeOptions`. An application can supply an authorizer when it
constructs `OperatorRuntime`; a denied decision emits `capability.denied` and
prevents capability execution.

The public root also exports `McpAdapter`. Its constructor requires the runtime
whose capabilities it exposes: `new McpAdapter(runtime)`. MCP tool calls are
translated into ordinary execution plans and use that runtime's governed
execution path. ADR-0006 records this public boundary and constructor decision.

The architecture remains locked at `v0.1.0-arch-lock`: plans execute through
`ExecutionPlan`, `OperatorRuntime`, and capabilities. MCP does not create an
alternate execution path.
