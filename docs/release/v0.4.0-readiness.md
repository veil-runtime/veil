## Filesystem security and platform limits

The final Linux run passes all nine regressions: positive/Unicode reads, lexical
traversal, final/parent/internal symlinks, hard links, sparse-file/directory rejection,
V1/V2 exploit rejection, policy-before-IO, portable identity-race simulation,
FIFO/socket rejection, pinned-parent replacement, final symlink swap and growth.
The provider still uses a fixed 200,001-byte buffer and 50,000-code-unit result cap.
The Linux path requires procfs and trusted root/ancestors/mount namespace.

macOS/Windows require host-owned, quiescent directories: Node does not provide a
portable descriptor-relative no-follow parent traversal primitive. Repeated
path/device/inode checks do not establish race-free confinement against a hostile
concurrent writer. Linux simulation does not replace actual native host tests.
Hostile mount changes, network filesystem semantics, content snapshots, general IO
cancellation and aggregate resource/concurrency quotas remain outside the guarantee.
See [filesystem confinement](../architecture/filesystem-confinement.md).

The source server remains a trusted loopback development host. Authentication,
tenant isolation, credential scoping and browser destination/redirect/SSRF policy
remain host-owned. This assignment adds no guarantee in those areas.

## Local Qwen timeout investigation

See [the detailed investigation](v0.4.0-qwen-investigation.md) and the committed
`tools/diagnose-local-planner.cjs` for a synthetic-only reproduction. Environment:
Ollama 0.32.14, `qwen3:0.6b`, installed model ID prefix `7df6b6e09427`.

The read succeeds. The original write wording instead selects `fixture.echo` and
fails its expected-write assertion. More explicit write wording with `/no_think`
reproduces the adapter deadline at 30,008 ms. Direct OpenAI streaming of that same
request receives bytes after 765 ms, produces 974 reasoning and 902 content
characters, then reaches the independent 30-second diagnostic deadline. Native
`think:false` completes in 1,728 ms but proposes an unwanted extra read before the
write. No write capability executes in any probe. The combined diagnostic exits 1.

This identifies a model/prompt/JSON-generation interaction with default thinking
configuration as the reproduced timeout's cause. It provides no evidence of a
transport outage, execution deadlock or broken adapter deadline. The exact October
23 timeout lacked streaming telemetry and cannot be assigned a definitive historical
cause. Raising deadlines or adding retries would not resolve wrong capability/step
selection. Generic adapter defaults and authority checks remain unchanged. The
native no-thinking experiment is diagnostic, not an implemented production fix.

## Documentation and remaining release blockers

Ruby, Bundler and Jekyll are absent. The available `docker` shim reports that
Docker is not integrated into this WSL2 distro, so it cannot supply a build either.
The existing Pages workflow builds Jekyll and then deploys; it was not invoked.
Source-link checks are recorded separately in the evidence and do not establish
rendered routes, layout behavior or Jekyll-generated fragment correctness.

Before changing the release recommendation:

1. Obtain actual macOS and Windows filesystem-suite results for this candidate;
   preserve the documented portable quiescent-directory limitation.
2. Build Jekyll without deployment and validate rendered links/fragments under
   `/veil`, navigation and layouts. This host cannot provide that evidence.
3. Resolve or explicitly scope the failed optional live write-planning acceptance
   criterion. No reliable-write or green combined-model-smoke claim is supported.
   Core's deterministic/application-owned planning and authorization gates pass.

The four quality reviews and separate client dependency advisories are resolved.
No architecture-lock decision was needed. Publication remains unauthorized and
was not attempted. The October 23 preparation record remains available in Git at
`9cff1e8:docs/release/v0.4.0-readiness.md`; current evidence supersedes its readiness
assessment and final artifact, while preserving its historical failed live smokes.
