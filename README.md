# Operator Runtime

Operator Runtime is a capability-driven execution engine that enables AI and software systems to safely interact with external systems through reusable providers and capabilities.

## Vision

Separate reasoning from execution.

Large language models decide *what* should happen.

The Operator Runtime decides *how* it happens safely, consistently and audibly.

## Current Features

- Capability Registry
- Generic Execution Engine
- Permission Model
- Audit Logging
- Browser Provider
- Session Manager
- LinkedIn capabilities
- Generic web page reader

## Roadmap

- Job Engine
- Planner
- Memory
- Provider SDK
- Operator UI
- Multi-provider orchestration
